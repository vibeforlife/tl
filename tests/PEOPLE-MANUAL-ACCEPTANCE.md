# People — manual desktop and mobile acceptance

Use a signed-in test account and non-production test data.

## Desktop
- [ ] Directory displays list and profile panes together.
- [ ] Search finds primary names and aliases.
- [ ] Selecting a person shows the correct profile and linked Memories.
- [ ] Renaming updates the profile and existing Memory display names after refresh.
- [ ] Inline creation from Add/Edit Memory automatically selects the new person.
- [ ] Removing a person from a Memory leaves the profile intact.
- [ ] Dashboard popup opens; Memory links and View full profile navigate correctly.
- [ ] Deleting a person confirms, removes associations, and preserves Memories.

## Mobile
- [ ] Directory initially shows the list; selecting a person replaces it with the profile.
- [ ] Back to people returns to the list and retains the search query.
- [ ] Search, inline creation, editing and deletion are usable at narrow width.
- [ ] Dashboard popup fits the viewport; close, Memory and profile actions work.

These checks are not considered passed until performed in a browser. Record any failure with browser, viewport width and reproduction steps.
